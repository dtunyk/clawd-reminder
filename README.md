# Clawd-нагадувач 🦀

Замість нудних сповіщень з краю екрана вилазить Clawd, каже «Через 30 хвилин — Урок математики» і ховається назад.

Програма для macOS (Apple Silicon). Сама бере події з програми «Календар» — iCloud, Google, Outlook, усе, що туди додано. Нічого вставляти не треба.

## Встановлення

1. Завантажте `Clawd Reminder-1.0.0.dmg` (або зберіть самі — див. нижче).
2. Відкрийте .dmg і перетягніть Clawd у папку «Програми».
3. **Перший запуск:** програма не підписана сертифікатом Apple, тому macOS скаже, що не може перевірити розробника. Натисніть «Готово», потім **Системні параметри → Приватність і безпека → «Все одно відкрити»**.
4. macOS спитає доступ до Календаря — натисніть **«Дозволити»**.

Програма живе в рядку меню (іконка — Clawd): там налаштування, тестовий показ і вихід.

## Звідки беруться події

З програми «Календар» на Mac, оновлюються кожні 2 хвилини. Події «на весь день» не нагадуються.

- **Google Calendar:** Системні параметри → **Інтернет-акаунти** → Google → увімкніть «Календарі».
- **Немає доступу?** Системні параметри → Приватність і безпека → **Календарі** → увімкніть Clawd Reminder (у налаштуваннях програми з'явиться кнопка, що відкриває це місце).

## Налаштування

- **За скільки хвилин нагадувати** — наприклад `30, 5` (два нагадування).
- **Звідки вилазить Clawd** — знизу, згори, зліва, справа або випадково.
- **Скільки секунд показувати** — клік по бульбашці ховає Clawd раніше.
- **Запускати разом із комп'ютером.**

## Розробка

Потрібні Node.js і Xcode (для Swift-помічника, що читає Календар).

```bash
npm install
```

```bash
npm start
```

Зібрати установщик (з'явиться в `dist/`):

```bash
npm run dist
```

## Структура

- `src/main.js` — рядок меню, розклад нагадувань, вікна
- `src/overlay.html` — анімація Clawd і бульбашка
- `src/settings.html` — вікно налаштувань
- `src/systemCalendar.js` + `native/calendar-helper.swift` — читання Календаря Mac (EventKit)
- `src/calendar.js` — розбір iCal-посилань (запасний варіант, у config.json)
- `src/clawd.js` — піксельна модель Clawd та іконка
